# How LLMs learn, taught straight to the viewer with one physical demonstration per idea

[  0.0s] s1 TITLE 第一課 猜字 / First Lesson: Guessing the Next Word
Come, sit with me. Today I will show you how a language machine learns. It is simpler than you fear.

[ 12.2s] s2
People ask me if it thinks. It does not. It reads text and guesses the next word. That is the whole trick.

[ 26.6s] s3
Each word becomes a row of numbers. Similar words get similar rows. Watch: the meaning is in how close they sit.

[ 40.3s] s4
Stack many layers. Each one mixes the numbers and passes them up. At the top, the highest score wins.

[ 51.8s] s5
It guesses. We show it the real word. Every number moves a little to close the gap, trillions of times.

[ 65.6s] s6 TITLE 戒 / The Caution
Now, one caution.

[ 68.8s] s7
It was never told what is true. Only what people wrote. If a lie is written often enough, the machine learns it like any fact.

[ 82.6s] s8
So it learned to sound right, not to be right. Remember that, and it will serve you well. Now, your tea is getting cold.
